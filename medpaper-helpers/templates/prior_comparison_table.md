# S16 前作对比表（Prior Comparison Table）模板

> 用途：写 Discussion 前，把本结果与既往研究（尤其竞争文献与已发表计数）逐行对比，防遗漏、防"声称首次发现"。本表与 `role_coverage_table.md` 的"对比文献"角色配合使用。

## 对比表

| 前作（citekey） | 前作结果（原文数字/结论，绑定 source_claims） | 本结果（结果 JSON 指针） | 一致/差异 | 差异解释方向 | 讨论落点（段落/句子） |
|---|---|---|---|---|---|
| feng2026agent | Table 3：阿哌沙班出血性胆囊炎 17 例、华法林 9 例、依度沙班胆道出血 9 例（来源：…fulltext… 位置） | primary_ror.json → …（本表型报告数） | 数量级一致/不一致 | 定义范围/时间窗/适应证层不同；不声称首次发现 | Discussion 第 X 段 |
| … | … | … | … | … | … |

## 规则

1. **前作数字必须绑定原文段落**（source_claims：全文身份核验 + 引文/页码 + 摘录 + 版本），不允许凭摘要/记忆写前作数字。
2. **本结果数字必须来自结果 JSON**（同数字事实包规则）。
3. 差异要给出可检验的解释方向（定义、范围、时间窗、适应证、方法差异），不写空泛的"可能与方法不同有关"。
4. 已知信号（前作已列出的计数）必须在表中出现并在 Discussion 正面承认——**禁止"首次发现/首次报道"式表述**（除非检索与核验确实没有前作，且表述为"尚未检出同设计专门研究"）。
5. 表本身不进正文，正文按表组织对比段落；表保存于项目记录（如 `03_analysis/prior_comparison.md`）。
