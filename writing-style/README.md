## 使用位置

- 每个写作阶段（S08/S09/S14/S16/S17 与摘要）写完 md → 按 `de-ai-polish.md` 检查清单执行 → 再过引擎语言门禁
- 摘要/引言/结论的自信表达与结构组织 → 参考 `anti-defensive-writing/SKILL.md`
- **医学诚信边界**：风格层只改"怎么说"，不改"说什么"——阴性/矛盾/不可估计结果、局限性与不确定性必须如实报告（工作流红线优先于任何风格指令）

## 对 anti-defensive-writing 的采纳边界（吸收 vs 保留）

该库的"发布会原则"偏"只突出优势"，医学论文**不能整体照搬**。取舍如下：

**✅ 吸收（叙事/论点层面的做法）**
- 去工作汇报式叙述：不按"先试 A、再试 B、最后选 C"写，而是"问题 X 关键 → 现有缺 Y → 本文做 Z → 证据如下"
- 明确论点：摘要/引言/结论围绕研究回答的问题组织；每个分析承担一个论证职责；结论只强化记忆点
- 不自我削弱：去掉无谓的"遗憾的是/效果有限/仍明显落后"式自我贬低（当它不代表事实需要时）；表达自信、直接陈述

**❌ 不吸收（会破坏医学诚信的部分）**
- "不占优的结果不说输""打不赢的指标不设为比赛""只讲最强优势"——**医学论文必须报告不利结果、零结果、局限性与不确定性**：
  - 不利结果（如药物组不良事件更多、效应方向与假设相反）→ 必须如实描述与解释
  - 零结果/阴性结果 → 必须报告（"未观察到差异""估计不可用"），不能隐藏或改写为阳性
  - 局限性 → 必须真实列出（数据源限制、缺失、偏倚风险等），不能为了自信而省略
  - 不确定性 → 如实表达（"证据有限""需进一步验证"），这不属于防御性写作
- 与既往文献不一致的发现 → 必须正面讨论，不能回避

**判别口诀**：把句子改成"更自信的表达"时，如果改动会**改变读者对事实的认知**（隐藏了不利、把不确定说成确定、把阴性说成阳性）→ 禁止；如果只是**改变陈述方式**（直接、聚焦、去掉无谓道歉）→ 采用。
